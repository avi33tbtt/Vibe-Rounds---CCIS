# `ccis/` folder

This folder holds the Clinical Context Intelligence Standard material.

## Now (Phase 0)

- `SPEC.md`: the draft specification in words, with requirement ids `CCIS-REQ-nnn` and the requirements matrix.
- `CHANGELOG.md`: version history and the amendment rule.

## Later: Stage 2, not started

These are planned and do **not** exist yet. They begin only after the Phase 0 review (gate R0) and the instruction "start stage 2".

- `schemas/`: JSON Schemas for the artefact families.
- `examples/`: small reference artefacts.
- `fixtures/`: synthetic test fixtures with hand-calculated expected results.
- `templates/`: starting templates for authors.

Prototype. Synthetic data only. Not for clinical use.
